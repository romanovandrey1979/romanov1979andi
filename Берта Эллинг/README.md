## Пересборка

```sh
cd 'Берта Эллинг/scripts'
SCRATCH=/tmp python3 make_elling.py ..
```

Нужны reportlab, openpyxl, matplotlib. Все исходные цифры — `scripts/elling_data.py` (объёмы, экспликация, расчёты) и `scripts/elling_cost.py` (цены по сценариям).
