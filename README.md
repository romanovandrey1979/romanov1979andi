# Берта Ромарио — раздел ОВК (вентиляция и кондиционирование)

Индивидуальный жилой дом из клееного бруса, Московская обл., Истринский р-н. Шифр раздела — **291-ОВК**.

## Состав

| Папка / файл | Содержание |
|---|---|
| `00_Исходные_данные/` | Исходники из Google Drive: КЖ0, КД1–КД5, РПЗ КЖ0/КД4/КД5 (9 PDF) |
| `ОВК/291-ОВК Чертежи.pdf` | Графическая часть, 9 листов А3: общие данные, расчёт воздухообмена, схемы П1, В1, П2/В3/В2/ЕВ1/ПЕ1/ПЕ2, К1/К2, спецификация |
| `ОВК/291-ОВК.РПЗ Расчётно-пояснительная записка.docx` | Пояснительная записка с расчётами |
| `ОВК/291-ОВК.Р Расчёты.xlsx` | Таблицы расчётов с формулами |
| `scripts/` | Python-скрипты, из которых всё генерируется |

## Основные решения

- **П1В1** — ПВУ с роторным рекуператором на чердаке, 1050/1050 м³/ч, догрев 3,5 кВт. 2 этаж — по чердаку круглыми воздуховодами; 1 этаж — лучевая разводка Ø90 в перекрытии от коллекторов в вентиляционных коробах.
- **В3 + П2** — кухонный зонт 450 м³/ч с компенсирующей приточкой 400 м³/ч (6 кВт).
- **В2** — вытяжка сауны 130 м³/ч (термостойкий вентилятор).
- **ЕВ1/ПЕ1** — естественная вентиляция котельной; **ПЕ2** — воздух на горение камина.
- **К1/К2** — две системы мини-VRF по этажам: 22,4 кВт (5 внутренних блоков) и 12,1 кВт (6 блоков).

## Что не хватает для полного комплекта

1. **«АПР Берта Ромарио.pdf» (13,6 МБ)** не скачивается коннектором Google Drive (лимит 10 МБ). Использован только его текстовый слой: экспликации, высоты, конструктив. Чтобы выпустить **планы трассировки**, нужен этот файл, например разбитый на части меньше 10 МБ или в DWG.
2. Тип котла, плиты, модель камина и зонта, места наружных блоков — см. раздел 8 РПЗ.
