# Дом «Ромарио» (посёлок «Берта», г. о. Истра, уч. 1) — инженерные разделы 291

**Статус: концепт заказчика — исходные данные для инженерного проектировщика (стадия «Э»).**
Не рабочая документация: расчёты подлежат независимой проверке, рабочий проект делает проектировщик
по тендеру (КП до 31.10.2026, старт 16.11.2026, полный комплект 15.02.2027).

Все решения заказчика — в `scripts/passport.py` (пакет исходных № 83 / 90б, эскизы БР-ОВ, БР-ОВК,
БР-ВК, БР-ЗК от 18.10.2026, решения 14–20.10, ТЗ автоматизации ред. 4).
