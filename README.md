## Основные решения

- **П1В1**: ПВУ с роторным рекуператором на чердаке (оси 7–9 / Е–К), 1050/1050 м³/ч, догрев 3,5 кВт. 2 этаж — потолочные диффузоры из чердака; 1 этаж — лучевая разводка Ø90 в перекрытии от коллекторов РК1–РК4 в коробах ВК-1 и ВК-4.
- **В3 + П2**: кухонный зонт 450 м³/ч с компенсирующей приточкой 400 м³/ч (6 кВт), через короб ВК-2.
- **В2**: вытяжка сауны 130 м³/ч через ВК-3.
- **ЕВ1/ПЕ1**: естественная вентиляция котельной (ВК-5); **ПЕ2**: воздух на горение камина.
- **К1/К2**: две системы мини-VRF по этажам: 22,4 кВт (5 настенных блоков) и 12,1 кВт (6 блоков); наружные блоки у котельной.

## Открытые вопросы

Тип котла и плиты, модели камина и зонта, увеличение коробов ВК-1…ВК-5 (см. лист 15), места блоков по дизайн-проекту.
